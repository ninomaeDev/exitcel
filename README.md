# Exitcel

ローカルで完結する、Excel ライクな表計算アプリです。
**外部ライブラリ・サーバー・インターネット接続は一切不要**（zip/xlsx の生成も自前実装）。

---

## 起動方法

### 方法1（推奨）`Exitcel を起動.bat` をダブルクリック
Node.js の簡易サーバー（`server.js`）が立ち上がり、Edge / Chrome の
アプリウィンドウ（アドレスバーなし）で開きます。
黒いコンソールウィンドウを閉じると終了します。

### 方法2 `index.html` をダブルクリック
ブラウザで直接開けます。ほぼ全機能が使えますが、
ブラウザによっては「名前を付けて保存」ダイアログが出ず、
直接ダウンロードフォルダに保存される場合があります。

## 保存とエクスポート

`ファイル` → `エクスポート` で形式を選べます。

| 形式 | 拡張子 | 内容 |
|---|---|---|
| Exitcel ブック | **`.exl`** | 独自形式。画像・図形・グラフ・罫線・結合・数式をすべて保持 |
| Excel ブック | **`.xlsx`** | Excel / LibreOffice / Google スプレッドシートで開けます |
| CSV | `.csv` | 現在のシートの値のみ（BOM 付きなので Excel で文字化けしません） |
| テキスト | `.tsv` | タブ区切り |
| JSON | `.json` | プログラムから扱いやすい形 |
| Web ページ | `.html` | ブラウザで表示・印刷できる形 |

`Ctrl+S` は `.exl` で保存します。
**読み込み**は `.exl` / `.xlsx` / `.csv` / `.tsv` / `.json` に対応（ドラッグ＆ドロップも可）。

> `.xlsx` に書き出すとき、グラフ・図形・テキストボックスは **画像として** 埋め込まれます
> （Excel 側で図として表示されます）。セルの値・数式・書式・罫線・結合・列幅・行高・
> ウィンドウ枠の固定は、Excel のネイティブ機能として書き出されます。

## 主な機能

**編集**
セル編集 / 数式バー / 複数行入力（Alt+Enter）/ コピー・切り取り・貼り付け（書式・数式ごと）/
オートフィル（連続データの自動生成）/ 元に戻す・やり直し（60 段階）/ 検索と置換 /
行・列の挿入と削除（数式の参照も自動追随）/ 列幅・行高のドラッグ変更と自動調整

**書式**
フォント・サイズ・太字・斜体・下線・取り消し線 / 文字色・塗りつぶし /
罫線（格子・外枠・太線・二重線など）/ 左右上下の配置・折り返し / セルの結合 /
表示形式（標準・数値・桁区切り・通貨・パーセント・指数・日付・時刻・文字列）

**数式**
119 個の関数を内蔵。SUM / AVERAGE / COUNTIF / SUMIFS / IF / IFERROR / VLOOKUP /
HLOOKUP / INDEX / MATCH / TEXT / DATEDIF / PMT / STDEV など。
シート間参照（`Sheet2!A1`、`'売上表'!A1`）、絶対参照（`$A$1`）、循環参照の検出に対応。

**挿入**
画像（ファイル選択・ドラッグ＆ドロップ・クリップボードから貼り付け）/
テキストボックス / メモ / 図形（四角形・楕円・矢印・直線）/
グラフ（縦棒・折れ線・円・面）。すべてドラッグ移動・ハンドルでサイズ変更できます。

**その他**
複数シート（追加・名前変更・コピー・並べ替え・削除）/ 並べ替え（昇順・降順）/
重複の削除 / 行列の入れ替え / ズーム（Ctrl+ホイール）/ ウィンドウ枠の固定 /
数式の表示 / 印刷 / 自動保存（ブラウザ内。次回起動時に復元）

## ショートカット

| キー | 動作 |
|---|---|
| `Ctrl+S` / `Ctrl+O` | 保存 / 開く |
| `Ctrl+Z` / `Ctrl+Y` | 元に戻す / やり直し |
| `Ctrl+C` `Ctrl+X` `Ctrl+V` | コピー / 切り取り / 貼り付け |
| `Ctrl+B` `Ctrl+I` `Ctrl+U` | 太字 / 斜体 / 下線 |
| `Ctrl+F` | 検索と置換 |
| `Ctrl+A` | シート全体を選択 |
| `Ctrl+方向キー` | データの端まで移動 |
| `Ctrl+;` | 今日の日付を入力 |
| `Ctrl+ホイール` | ズーム |
| `F2` | セルの編集 |
| `Alt+Enter` | セル内で改行 |
| `Delete` | 内容のクリア / 選択中の図の削除 |

## ファイル構成

```
Exitcel/
├─ index.html            画面の構造
├─ css/style.css         見た目
├─ js/util.js            A1 参照変換・表示形式エンジン
├─ js/formula.js         数式パーサ・評価器・関数ライブラリ（119 関数）
├─ js/model.js           ブック/シート/セルのモデル・再計算・Undo
├─ js/xlsxio.js          ZIP 実装 と xlsx / csv / html 入出力
├─ js/objects.js         画像・図形・テキストボックス・グラフ
├─ js/grid.js            グリッド描画（仮想スクロール）と操作
├─ js/app.js             リボン・ダイアログ・ファイル操作
├─ server.js             起動用の簡易ローカルサーバー
└─ Exitcel を起動.bat    ランチャー
```

> **メモ:** `Exitcel を起動.bat` は **改行 CRLF・文字コード Shift-JIS(CP932)** で保存されています。
> cmd.exe は LF だけの .bat を正しく解釈できず「実行するとすぐ閉じる」原因になるため、
> 編集する場合はこの形式を保ってください（他のファイルは UTF-8 / LF のままで問題ありません）。
