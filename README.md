# Exitcel

**ブラウザだけで動く、Excel のような表計算アプリです。**

インストール作業はありません。ダウンロードして展開して、ファイルをダブルクリックするだけで使えます。
アカウント登録も、インターネット接続も、追加ソフトも要りません。入力したデータがどこかに送信されることもありません。

数式は 119 種類、グラフや画像も置けて、`.xlsx` で書き出せば Excel でそのまま開けます。

---

## はじめての方へ — 使うまでの3ステップ

### ステップ1　ダウンロードする

1. このページの上のほう、ファイル一覧の**右上にある緑色の `< > Code` ボタン**を押します
2. 開いたメニューのいちばん下の **`Download ZIP`** を押します
3. `exitcel-main.zip` というファイルがダウンロードフォルダに入ります

### ステップ2　ZIP を展開する（ここが大事です）

ダウンロードした ZIP ファイルは、**必ず「展開」してから使ってください。**

ZIP をダブルクリックすると中身が見えますが、それは*中を覗いているだけ*の状態です。
そのまま起動しても正しく動きません。よくあるつまずきどころなので、先にここを済ませてしまいましょう。

**Windows の場合**

1. `exitcel-main.zip` を**右クリック**
2. **「すべて展開」**を選ぶ
3. 出てきた画面で**「展開」**を押す
4. `exitcel-main` というフォルダができます

**Mac の場合**

ZIP ファイルをダブルクリックすると、同じ場所にフォルダができます。それで完了です。

### ステップ3　起動する

展開してできたフォルダを開くと、中にもう一つ同じ名前のフォルダがあることがあります。
**`index.html` が見えるところまで**進んでください。そこが本体です。

#### Windows の方

**`Exitcel を起動.bat`** をダブルクリックします。

- 「**WindowsによってPCが保護されました**」という青い画面が出たら、
  **「詳細情報」** → **「実行」** の順に押してください。
  これは「作者が確認されていないファイル」に対して Windows が毎回出す警告で、
  中身は下の[ファイル構成](#ファイル構成)のとおり、テキストのファイルだけです。
- 黒いウィンドウが出たあと、Exitcel の画面が開きます。
- **黒いウィンドウは閉じないでください。**閉じると Exitcel も終了します。
  使い終わるときは、この黒いウィンドウを閉じれば終了できます。

#### Mac・その他の方、または上がうまくいかない方

**`index.html`** をダブルクリックしてください。いつものブラウザで開きます。
これだけでも、ほぼすべての機能が使えます。

## 2つの起動方法の違い

どちらでも使えます。迷ったら Windows なら `.bat`、それ以外なら `index.html` で大丈夫です。

| | `Exitcel を起動.bat` | `index.html` |
|---|---|---|
| 対応 OS | Windows のみ | どの OS でも |
| 見た目 | アドレスバーのないアプリの窓 | いつものブラウザのタブ |
| ファイルの保存 | 「名前を付けて保存」で保存先を選べる | ダウンロードフォルダに直接入る |
| Node.js | あれば使う（無ければ自動で `index.html` を開きます） | 不要 |

> **Node.js は必須ではありません。**
> 入っていなくても `.bat` は自動で `index.html` を開くので、そのまま使えます。
> 「保存先を選べるほうがいい」という方だけ、[nodejs.org](https://nodejs.org/ja) から入れてください。
> インストール後は何も設定せず、`.bat` をダブルクリックし直すだけです。

## 困ったときは

**黒いウィンドウが一瞬出てすぐ消える**
ZIP を展開せずに、ZIP の中身から直接実行している可能性が高いです。
上の「ステップ2　ZIP を展開する」に戻って、展開してから起動してください。

**「WindowsによってPCが保護されました」から先に進めない**
「詳細情報」という小さな文字を押すと、「実行」ボタンが現れます。

**`Port 8777 is already in use.` と出る**
他のソフトが同じ番号を使っています。黒いウィンドウで次のように打つと別の番号で起動できます。

```
node server.js 8888
```

**保存したファイルが見つからない**
`index.html` から起動した場合は、保存先を聞かれずにダウンロードフォルダへ入ります。

**前に作った表が消えた**
自動保存は**使ったブラウザの中**に保存されます。別のブラウザで開いたり、
閲覧履歴を消したりすると残りません。大事な表は `ファイル` → `エクスポート` から
`.exl` か `.xlsx` で保存してください。

**アンインストールしたい**
フォルダごとゴミ箱に入れてください。それだけです。
インストーラを使っていないので、パソコンの設定やレジストリには何も残りません。

## 保存とエクスポート

`ファイル` → `エクスポート` で形式を選べます。

| 形式 | 拡張子 | 内容 |
|---|---|---|
| Exitcel ブック | **`.exl`** | 独自形式。画像・図形・グラフ・罫線・結合・数式をすべて保持 |
| Excel ブック | **`.xlsx`** | Excel / LibreOffice / Google スプレッドシートで開けます |
| CSV | `.csv` | 現在のシートの値のみ（BOM 付きなので Excel で文字化けしません） |
| テキスト | `.tsv` | タブ区切り |
| JSON | `.json` | プログラムから扱いやすい形 |
| Web ページ | `.html` | ブラウザで表示・印刷できる形 |

`Ctrl+S` は `.exl` で保存します。
**読み込み**は `.exl` / `.xlsx` / `.csv` / `.tsv` / `.json` に対応（ドラッグ＆ドロップも可）。

> `.xlsx` に書き出すとき、グラフ・図形・テキストボックスは **画像として** 埋め込まれます
> （Excel 側で図として表示されます）。セルの値・数式・書式・罫線・結合・列幅・行高・
> ウィンドウ枠の固定は、Excel のネイティブ機能として書き出されます。

## 主な機能

**編集**
セル編集 / 数式バー / 複数行入力（Alt+Enter）/ コピー・切り取り・貼り付け（書式・数式ごと）/
オートフィル（連続データの自動生成）/ 元に戻す・やり直し（60 段階）/ 検索と置換 /
行・列の挿入と削除（数式の参照も自動追随）/ 列幅・行高のドラッグ変更と自動調整

**書式**
フォント・サイズ・太字・斜体・下線・取り消し線 / 文字色・塗りつぶし /
罫線（格子・外枠・太線・二重線など）/ 左右上下の配置・折り返し / セルの結合 /
表示形式（標準・数値・桁区切り・通貨・パーセント・指数・日付・時刻・文字列）

**数式**
119 個の関数を内蔵。SUM / AVERAGE / COUNTIF / SUMIFS / IF / IFERROR / VLOOKUP /
HLOOKUP / INDEX / MATCH / TEXT / DATEDIF / PMT / STDEV など。
シート間参照（`Sheet2!A1`、`'売上表'!A1`）、絶対参照（`$A$1`）、循環参照の検出に対応。

**挿入**
画像（ファイル選択・ドラッグ＆ドロップ・クリップボードから貼り付け）/
テキストボックス / メモ / 図形（四角形・楕円・矢印・直線）/
グラフ（縦棒・折れ線・円・面）。すべてドラッグ移動・ハンドルでサイズ変更できます。

**その他**
複数シート（追加・名前変更・コピー・並べ替え・削除）/ 並べ替え（昇順・降順）/
重複の削除 / 行列の入れ替え / ズーム（Ctrl+ホイール）/ ウィンドウ枠の固定 /
数式の表示 / 印刷 / 自動保存（ブラウザ内。次回起動時に復元）

## ショートカット

| キー | 動作 |
|---|---|
| `Ctrl+S` / `Ctrl+O` | 保存 / 開く |
| `Ctrl+Z` / `Ctrl+Y` | 元に戻す / やり直し |
| `Ctrl+C` `Ctrl+X` `Ctrl+V` | コピー / 切り取り / 貼り付け |
| `Ctrl+B` `Ctrl+I` `Ctrl+U` | 太字 / 斜体 / 下線 |
| `Ctrl+F` | 検索と置換 |
| `Ctrl+A` | シート全体を選択 |
| `Ctrl+方向キー` | データの端まで移動 |
| `Ctrl+;` | 今日の日付を入力 |
| `Ctrl+ホイール` | ズーム |
| `F2` | セルの編集 |
| `Alt+Enter` | セル内で改行 |
| `Delete` | 内容のクリア / 選択中の図の削除 |

## ファイル構成

```
Exitcel/
├─ index.html            画面の構造
├─ css/style.css         見た目
├─ js/util.js            A1 参照変換・表示形式エンジン
├─ js/formula.js         数式パーサ・評価器・関数ライブラリ（119 関数）
├─ js/model.js           ブック/シート/セルのモデル・再計算・Undo
├─ js/xlsxio.js          ZIP 実装 と xlsx / csv / html 入出力
├─ js/objects.js         画像・図形・テキストボックス・グラフ
├─ js/grid.js            グリッド描画（仮想スクロール）と操作
├─ js/app.js             リボン・ダイアログ・ファイル操作
├─ server.js             起動用の簡易ローカルサーバー
├─ qa/                   テスト成果物（テストケース・不具合票・実行スクリプト）
└─ Exitcel を起動.bat    ランチャー
```

外部ライブラリは一つも使っていません（`.xlsx` を作るための ZIP 圧縮も自前実装です）。
そのため `npm install` のような準備作業も不要です。

> **開発者向けメモ:** `Exitcel を起動.bat` は **改行 CRLF・文字コード Shift-JIS(CP932)** で保存されています。
> cmd.exe は LF だけの .bat を正しく解釈できず「実行するとすぐ閉じる」原因になるため、
> 編集する場合はこの形式を保ってください（他のファイルは UTF-8 / LF のままで問題ありません）。
